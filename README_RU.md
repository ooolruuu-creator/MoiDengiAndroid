# Мои деньги — Android

Локальное Android-приложение для личного учёта доходов и расходов в UZS.

## Возможности
- Доходы и расходы с категориями и заметками.
- Локальная база SQLite — записи сохраняются между запусками приложения.
- Дневной и месячный лимиты.
- Красное отображение суммы при превышении лимита и короткая вибрация при первом пересечении.
- Голосовой ввод через системную службу распознавания Android; после распознавания пользователь проверяет и подтверждает запись.
- Выбор языка голосового ввода: русский или узбекский; базовое распознавание категорий и сумм.

## Сборка APK
1. Установите Android Studio (актуальную стабильную версию) и Android SDK Platform 35.
2. Откройте папку `MoiDengiAndroid` в Android Studio.
3. Дождитесь синхронизации Gradle и установки зависимостей.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Либо из терминала с установленным Android SDK и Gradle:
`gradle assembleDebug`

## Установка
Скопируйте `app-debug.apk` на телефон Android и установите. При первом голосовом вводе разрешите доступ к микрофону, если Android запросит его.

## Важные ограничения первой версии
- Голосовой ввод использует установленный на телефоне системный распознаватель речи. Доступность русского/узбекского языка и работа без интернета зависят от устройства и установленного сервиса.
- Распознавание — эвристическое: перед сохранением обязательно проверьте сумму и категорию. Не используйте приложение и голосовой ввод во время управления автомобилем; настройте запись только после безопасной остановки.
- Данные хранятся локально на устройстве; экспорт/облачная синхронизация в этой версии не реализованы.
- APK не включён в архив: в среде подготовки отсутствуют Android SDK и Gradle, поэтому собрать и проверить бинарный APK здесь не удалось.


## Сборка APK через GitHub Actions (если на ПК нет Android SDK)
1. Создайте пустой репозиторий GitHub.
2. Загрузите в него всё содержимое этой папки (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** и запустите workflow **Build Android APK** через **Run workflow**.
4. После успешной сборки скачайте артефакт **MoiDengi-debug-apk** из завершённого запуска.

GitHub Actions использует Android SDK на виртуальном runner и собирает `app-debug.apk`.
